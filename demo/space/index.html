Kiln

An LLM inference engine built from scratch, running Qwen2.5-0.5B on two free CPU cores. Source and benchmarks.

A burst fires 6 requests at once behind one shared system prompt. Watch the KV cache: they join the same running batch, share the prompt's blocks (orange), and leave cached blocks (green) behind.

Everyone here sees the same KV-cache view. It shows block usage and token counts, never text, but don't type anything private.
